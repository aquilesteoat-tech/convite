# Convite interativo para a Ana Vitória

Site estático (HTML, CSS e JavaScript puro). Sem backend, sem banco de dados e sem envio de dados: tudo acontece na própria página.

## Arquivos
- `index.html`: estrutura das telas
- `style.css`: visual e animações
- `script.js`: navegação, botões fujões, resumo e cópia

## Testar no computador
Abra o `index.html` no navegador. Não precisa instalar nada.

## Publicar no GitHub Pages (gratuito)
1. **Conta:** acesse github.com, clique em *Sign up* e confirme o e-mail.
2. **Repositório:** clique em *New repository*, dê um nome (ex.: `convite`), marque **Public** e clique em *Create repository*.
3. **Enviar arquivos:** na página do repositório, clique em *uploading an existing file*, arraste os quatro arquivos (`index.html`, `style.css`, `script.js`, `README.md`) e clique em *Commit changes*. Eles devem ficar na raiz, sem pasta.
4. **Settings → Pages:** no repositório, abra *Settings* e, no menu lateral, *Pages*.
5. **Fonte:** em *Build and deployment*, escolha *Deploy from a branch*, selecione a branch `main` e a pasta `/ (root)`, e clique em *Save*.
6. **Endereço:** aguarde 1 a 3 minutos e atualize a página. Aparece o link, no formato `https://SEU-USUARIO.github.io/convite/`.
7. **Teste no celular:** abra o link no Android (de preferência no Chrome), teste os botões fujões, todas as telas e o botão de copiar. Depois envie pelo WhatsApp.

## Observações
- Se o botão "Copiar resumo" não puder copiar, o site mostra o texto já selecionado para copiar manualmente.
- O botão "Abrir no WhatsApp" abre o app com o resumo pronto; você escolhe o contato.
